# Restaurant Machine Learning Project

This project was developed as part of a Machine Learning Internship.  
The goal is to analyze restaurant data and build machine learning models for prediction, recommendation, and classification.

---

## 📌 Tasks Completed

### Task 1 – Restaurant Rating Prediction
Built a regression model to predict restaurant ratings using features such as:
- Votes
- Average Cost for Two

Algorithms used:
- Linear Regression

Evaluation Metrics:
- Mean Squared Error (MSE)
- R² Score

---

### Task 2 – Restaurant Recommendation System
Developed a content-based recommendation system.

Features used:
- Cuisines
- Average Cost for Two

Techniques used:
- Text Vectorization (CountVectorizer)
- Cosine Similarity

The system recommends similar restaurants based on user input.

---

### Task 3 – Cuisine Classification
Implemented a machine learning model to classify restaurant cuisines.

Algorithm used:
- Random Forest Classifier

Evaluation Metrics:
- Accuracy
- Precision
- Recall

---
